# Einmaliger Upload zu GitHub

Die einfachste Methode funktioniert auf einem Windows-PC oder Mac mit **GitHub Desktop**.

1. GitHub Desktop installieren und mit dem Benutzer `Rohner96` anmelden.
2. `File` → `Clone repository` wählen.
3. Das Repository `rohner-transport/rohner-dispo` auswählen und klonen.
4. Diese ZIP-Datei entpacken.
5. Den Inhalt des entpackten Ordners in den von GitHub Desktop geklonten Ordner kopieren. Die vorhandene `README.md` darf ersetzt werden.
6. In GitHub Desktop unten links als Beschreibung `Version 1.0.0 Menü, Startseite und Einstellungen` eingeben.
7. `Commit to main` und danach `Push origin` wählen.

Nicht die ZIP-Datei selbst als einzelne Datei hochladen. GitHub soll die entpackten Projektdateien versionieren.
